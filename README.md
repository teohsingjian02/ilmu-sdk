# ILMU Avatar SDK web demo

[Open ILMU](https://teohsingjian02.github.io/ilmu-sdk/) to practise SPM Sejarah and Mathematics in Bahasa Melayu or English. Choose from Alya, Hana, Aina, Zara, Maya and Nuri. The Studio tab includes a recorded Malay greeting that demonstrates the avatar's lip sync.

The site runs on GitHub Pages. Built-in practice answers and the recorded greeting work directly in the browser. For live AI replies, set the speech endpoint in Studio to an ILMU backend served over HTTPS. The backend must allow the origin `https://teohsingjian02.github.io` and hold the AI and text-to-speech credentials server-side.

The project uses its own campus motion library. See [the campus asset notice](licenses/campus-demo-CC0.txt), [the three.js license](licenses/three.js.txt) and [the Roboto license](fonts/Roboto-OFL.txt).
